## 📊 Project Overview

This project presents a comprehensive end-to-end sales analysis of a chocolate manufacturing and distribution dataset using Microsoft Excel. The goal was to convert raw sales transaction data into valuable business insights through exploratory data analysis, profitability evaluation, anomaly detection, and interactive reporting.

**Dataset:** 300+ chocolate sales transactions collected from multiple countries.

---

## 🛠 Skills Applied

- Pivot Tables & Pivot Charts
- Advanced Excel Functions (XLOOKUP, SUMIFS, IF)
- Conditional Formatting
- Data Validation
- Exploratory Data Analysis (EDA)
- Profitability Analysis
- Sales Anomaly Detection
- Interactive Reporting

---

## 📌 Project Highlights

- Performed descriptive statistical analysis to summarize sales performance.
- Analyzed sales trends across different countries.
- Evaluated product profitability to identify top-performing products.
- Assessed salesperson performance to determine the best contributors.
- Identified unusual sales patterns through anomaly detection.
- Developed a dynamic country-level sales reporting system.
- Recommended products for discontinuation based on performance analysis.
